# Olist Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes sales performance of Olist (Brazilian e-commerce platform) using SQL and Power BI.
The goal is to extract business insights related to revenue, customer behavior, and regional performance.

---

## 🛠 Tech Stack
- SQL (MySQL)
- Power BI
- Excel (optional for validation)
- GitHub

---

## 📂 Dataset
Olist Brazilian E-Commerce Public Dataset  
Source: Kaggle

Tables used:
- customers
- orders
- order_items
- order_payments
- order_reviews
- sellers
- geolocations

---

## ⚙️ Project Workflow
1. Imported raw CSV files into MySQL
2. Cleaned and transformed data using SQL
3. Created business KPIs:
   - Total Revenue
   - Total Orders
   - Average Order Value
   - Monthly Revenue Growth
   - State-wise Revenue
4. Exported SQL results to Power BI
5. Designed interactive dashboard

---

## 📊 Dashboard Insights
- Revenue trend shows steady growth over time
- Top states contribute majority of total revenue
- High concentration of repeat customers
- Average order value around 158
